# 共用頁首與頁尾

所有頁面沿用圓心角與扇形比例頁的結構。頁首左側顯示單元圖示、名稱和「數學探索室」，右側排列數學入口、目前單元、相關頁面與全螢幕。頁尾左側顯示站名和標語，右側放本頁提示。行動版導覽換行，列印時隱藏頁首與頁尾。

新增頁面時，先提供一個頁首、頁尾與主要內容的 HTML 結構，再把單元資料加入 `sync-page-shell.py` 的 `LESSONS`，並從專案根目錄執行：

```sh
python3 scripts/sync-page-shell.py
```

提交更新後的 HTML。部署直接使用 `dist/`，不需要額外執行產生腳本。共用樣式和全螢幕行為分別由 `dist/site-shell.css` 與 `dist/site-shell.js` 維護。
