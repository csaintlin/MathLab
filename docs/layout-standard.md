# 小小數學所版型標準

新增探索單元時，以 [三角形探索室](../dist/triangle.html) 與 [三角形小挑戰](../dist/triangle-quiz.html) 為母版。首頁保留年級與學期入口的版型，新增單元沿用既有卡片。

## 導覽與練習入口

| 位置 | 標準 |
|---|---|
| 探索頁頁首 | 數學入口、探索頁、隨機練習、全螢幕。數學入口連回所屬年級。 |
| 練習頁頁首 | 沿用同一組導覽，標示目前所在的「隨機練習」。 |
| 首頁單元卡 | 主要連結「開始探索」，次要連結「五題小挑戰」等符合實際題數的文字。 |
| 練習頁標題區 | 標題旁放「↻ 再出 N 題」，N 與實際題數一致。 |
| 練習頁題目下方 | 顯示作答狀態與主要按鈕「檢查全部答案」。 |

探索頁的練習入口集中在頁首。首頁單元卡可直接連到練習。尚無練習的單元省略練習入口。頁尾與浮動「意見回饋」由共用頁首、頁尾與指令碼提供。

## 探索頁

- 內容區最大寬度 1440 px，左右留白 5%。標題與簡介使用 `.intro`、`h1`、`.subtitle`。
- 多題型或模式先放切換，操作選項另起一列。右側同時有題型與選項時，兩列使用 `.grade3-control-row`，各自可換行。
- 需要兩欄時，使用 `.triangle-layout`。左側 `.board-card` 放圖形或主要操作，右側 `.readout-card` 放控制項、即時結果或觀察提示。寬版欄寬約 1.8:1，欄距 20 px。900 px 以下堆疊成單欄，圖形在前。
- 容量觀察等分步活動可以依操作順序排列，餅乾袋等多區塊活動可以保留專用排列。標題、外距、卡片與按鈕仍沿用全站樣式。

## 練習頁

- 沿用既有測驗框架。題目使用 `#questions.question-grid`，寬版兩欄，760 px 以下一欄。
- 每張題卡依序放題號與題型、題目與必要圖像、作答區、回饋與解題說明。
- 題目可重新作答，出新題時清除舊作答和評分。填數字使用文字欄位搭配 `inputmode="numeric"` 或 `inputmode="decimal"`，避免滾輪改值。

## 按鈕

| 用途 | 樣式與共用類別 |
|---|---|
| 主要操作 | 深綠實底、白字、9 px 圓角。使用 `.primary`，例如檢查全部答案或確認組合。 |
| 次要操作 | 淺底、綠色文字與淺綠描邊、9 px 圓角。沿用 `.small-button`、`.new-set` 或 `.lab-controls` 內的按鈕，例如換題、重設。 |
| 切換模式 | 沿用 `.activity-tabs`，或用 `aria-pressed` 表示互斥模式的選取狀態。 |
| 操作圖形 | 方格、色塊與頂點保留教學所需的外觀，並提供可辨識的選取及鍵盤焦點。 |

主要及次要操作按鈕至少 44 px 高。樣式在 `dist/site-shell.css`，新增單元時用共用類別，避免另寫相同用途的行內樣式。

## 新增單元時

1. 在 `scripts/sync-page-shell.py` 的 `LESSONS` 登記探索頁、名稱、年級和練習頁路徑。
2. 建立探索頁與練習頁，沿用母版結構與 `site-shell.css`、`site-shell.js`。
3. 執行 `python3 scripts/sync-page-shell.py`，產生頁首、頁尾和 `data-site-layout`。
4. 在首頁所屬年級與學期加入單元卡，核對入口、題數與回到單元的連結。
5. 發布前用桌面與窄版各檢查一次。確認題型與操作分列、按鈕主次清楚、圖形與題卡無水平溢出，並試做換題、作答、檢查和返回。
